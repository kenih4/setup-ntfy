# 山間部（電波・Wi-Fiなし）でPC→スマホに通知を送る手順

Bluetooth PAN経由でPCとスマホの間にネットワークを作り、PC上のntfyサーバーに向けて
curlで通知を送る仕組みです。

## 前提

- PC: Windows
- スマホ: Android
- PCは会社Wi-Fiなどにつないだまま、Bluetooth経由で別のネットワークを追加で作る

## 手動で行う手順（スクリプトでは自動化できません）

以下は物理操作・スマホ側のGUI操作のため、現地で毎回（または初回に）手動で行う必要があります。

1. **PCとスマホをBluetoothでペアリングする**
   （初回のみでOK。一度ペアリングすれば以降は不要）

2. **スマホでBluetoothテザリングをONにする**
   「設定 → ネットワークとインターネット → テザリング」あたり（機種により名称が異なる）

3. **PCからスマホに「アクセスポイント」として接続する**
   コントロールパネル →「デバイスとプリンター」→ スマホを右クリック →
   「接続方法」→「アクセスポイント」を選択

4. **スマホのntfyアプリで、購読先サーバーを指定する**（初回のみでOK）
   `setup-ntfy.ps1` の実行結果に表示される `http://<PCのIP>:8080` を、
   ntfyアプリの「サーバーURL」に入力してトピックを購読する

## スクリプトで自動化している部分

上記1〜4が済んだ状態であれば、以下はスクリプトにまとめてあります。

### `setup-ntfy.ps1`（PCの準備・ntfy起動）

「管理者として実行」した PowerShell で実行します。

```powershell
.\setup-ntfy.ps1
```

このスクリプトが行うこと:
- ファイアウォールで8080番ポートの受信を許可（未登録なら追加）
- Bluetooth PANアダプタのIPv4アドレスを自動検出
- 検出したIPを `ntfy_ip.txt` に保存（`notify.ps1` が読み取る）
- ntfyサーバーを起動（`Ctrl+C` で終了）

`ntfy.exe` にPATHが通っていない場合:
```powershell
.\setup-ntfy.ps1 -NtfyPath "C:\ntfy\ntfy.exe"
```

### `notify.ps1`（通知送信）

`setup-ntfy.ps1` でサーバーを起動した状態で、別のPowerShellから実行します。

```powershell
.\notify.ps1 -Message "ビルド完了"
```

トピック名やポートを変える場合:
```powershell
.\notify.ps1 -Message "ビルド完了" -Topic "mytopic" -Port 8080
```

## 注意点

- **出発前に必ず一度、家や会社で一連の流れを通しでテストする**
  （現地ではアプリのインストールやダウンロードができないため）
- PCを再起動するとBluetooth PAN側のIPアドレスが変わることがある
  → その場合は `setup-ntfy.ps1` をもう一度実行してIPを取得し直す
- スマホ側は、ntfyアプリをバッテリー最適化の対象外にしておくと、
  画面オフ時も通知を受信しやすい
- テザリングはスマホのバッテリー消費が増えるため、モバイルバッテリー等を用意しておくと安心
