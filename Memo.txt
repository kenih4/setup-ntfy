＜setup-ntfy.ps1をPC起動時に自動で実行するようにしたい＞
PowerShellコマンドで一括登録

管理者権限のPowerShellで、次を1回実行すれば同じ内容のタスクが登録されます
$scriptPath = "C:\Users\kenic\Dropbox\gitdir\setup-ntfy\setup-ntfy.ps1"
$action = New-ScheduledTaskAction -Execute "powershell.exe" `
    -Argument "-ExecutionPolicy Bypass -File `"$scriptPath`""
$trigger = New-ScheduledTaskTrigger -AtLogOn
$principal = New-ScheduledTaskPrincipal -UserId $env:USERNAME -LogonType Interactive -RunLevel Highest
Register-ScheduledTask -TaskName "ntfy-autostart" -Action $action -Trigger $trigger -Principal $principal

タスクが登録されているか確認する方法
Get-ScheduledTask -TaskName "ntfy-autostart"

ログオンし直さなくても、タスクスケジューラのGUIか、次のコマンドでその場実行できます。
Start-ScheduledTask -TaskName "ntfy-autostart"


タスクを止めたい・削除したい場合
Unregister-ScheduledTask -TaskName "ntfy-autostart" -Confirm:$false


＜登録済みタスクの設定変更（管理者権限のPowerShellで実行）＞
・コンソールを表示する（-WindowStyle Hidden を外す）
・エラーで止まってもウィンドウを残す（-NoExit）
・バッテリー駆動でも開始・継続する
・実行時間の上限（既定72時間）をなくす
※ウィンドウを閉じるとntfyサーバーも止まるので、邪魔なら最小化する

実行中のタスクを止める（入力待ちで止まっている場合など）
Stop-ScheduledTask -TaskName "ntfy-autostart"

設定を変更する
$scriptPath = "C:\Users\kenic\Dropbox\gitdir\setup-ntfy\setup-ntfy.ps1"
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoExit -ExecutionPolicy Bypass -File `"$scriptPath`""
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit ([TimeSpan]::Zero)
Set-ScheduledTask -TaskName "ntfy-autostart" -Action $action -Settings $settings

変更内容を確認する
(Get-ScheduledTask -TaskName "ntfy-autostart").Actions.Arguments
(Get-ScheduledTask -TaskName "ntfy-autostart").Settings | Format-List DisallowStartIfOnBatteries, StopIfGoingOnBatteries, ExecutionTimeLimit

＜どのBluetoothプロファイルで接続されているか確認する方法＞
この通信は PAN（Personal Area Network Profile）。PCが NAP（ネットワーク提供側、192.168.138.1）、スマホが PANU（参加側）。
※スマホの「電話」「メディアのオーディオ」「連絡先と通話履歴へのアクセス」は別のプロファイル（HFP / A2DP / PBAP）で、この通信には無関係

1. PANアダプタの状態（Status が Up なら PAN で接続中）
Get-NetAdapter | Where-Object InterfaceDescription -match "Personal Area Network"

2. ホットスポットに接続している端末（PCがNAPで、スマホが参加していることの確認）
   設定 > モバイル ホットスポット の「接続されているデバイス」でも見られる
Add-Type -AssemblyName System.Runtime.WindowsRuntime
$null = [Windows.Networking.Connectivity.NetworkInformation, Windows.Networking.Connectivity, ContentType = WindowsRuntime]
$null = [Windows.Networking.NetworkOperators.NetworkOperatorTetheringManager, Windows.Networking.NetworkOperators, ContentType = WindowsRuntime]
$p = [Windows.Networking.Connectivity.NetworkInformation]::GetConnectionProfiles() | Select-Object -First 1
$m = [Windows.Networking.NetworkOperators.NetworkOperatorTetheringManager]::CreateFromConnectionProfile($p)
$m.GetTetheringClients() | ForEach-Object { $_.MacAddress; $_.HostNames.DisplayName }

3. スマホ側
   設定 > Bluetooth >「SES」の ⚙ で「インターネット アクセス」がON・接続済みなら PANU として接続中

※プロファイルごとの接続状態を一覧する標準の方法はない（デバイスのプロパティでは機器全体の接続状態しか分からない）。
  実際の通信を見たい場合は、Bluetooth Virtual Sniffer（BTVS）+ Wireshark、またはAndroidの開発者向けオプション
  「Bluetooth HCI スヌープログ」で記録すると、BNEP（PANの通信）が流れているのを確認できる
